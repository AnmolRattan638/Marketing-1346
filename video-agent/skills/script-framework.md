# Script framework: Pain, Poke, Fix, Payoff, Recap, CTA

A reel is written as a script BEFORE anything is shot or drawn. Every video follows this 6-beat arc (taught in a scriptwriting reel by a Hinglish creator;
the beat names and the "first line = pain" idea are his, the wording below is ours). It works for any niche and for beginners. Put the beat in each scene's `beat` field.

1. `pain` (the hook, the FIRST line). One deep, specific pain the viewer has ALREADY felt, said to a clear audience ("If you write scripts without thinking..."). The viewer must
   think "arre, yeh to mere saath bhi hota hai". Clear and to the point: ONE pain, no intro, no greeting, no "in this video".
2. `poke`. Press on it: the obvious solution everyone tries does not really work (name it, then break it). This opens a curiosity gap: "so what does?".
3. `fix`. The real solution in a few clear steps (2 to 4, one short line each). This is the longest beat. Concrete, doable today, no theory.
4. `payoff`. Show the result: a number, a before/after, a client outcome. Proof beats claims. Only use facts from the research or the topic, never invent figures.
5. `recap`. One line that sums it up and loops back to the first line's pain, almost word for word, so the end connects to the start (the reel replays well).
6. `cta`. One clear ask (follow / comment a keyword / save), tied to what the viewer just got. Never two asks.

Variants (pick one per video, so scripts do not all look alike):
- Full: all six beats (25 to 40 s).
- Short: pain, fix, payoff, cta (15 to 22 s).
- Myth-first: pain is a myth the viewer believes; poke is "here is why that fails"; the rest as usual.
- Loop: recap repeats the pain line exactly and the video ends mid-thought into the first scene.

Rules: the pain beat is always scene 1. Beats keep this order and each appears at most once, except `fix` which may span two scenes. Spoken lines are short (5 to 14 words), plain,
conversational, in the narration language, one idea per line. Every beat is also a different picture (see the graphic layouts): pain = bold `title` or `punch`, poke = `strike` (the
obvious things crossed out), fix = `step` with a `checklist`/`terminal`/`browser` mock, payoff = a `stat` fx or `punch`, recap = `title`, cta = the logo outro.
